# Filmix для Lampa

Плагин-источник для [Lampa](https://github.com/yumata/lampa): фильмы и сериалы с Filmix, выбор озвучки, сезона и качества (до 4K), таймкоды, отметки «просмотрено».

```
plugin/filmix.js    — плагин Lampa (ES5, без сборки)
proxy/worker.js     — прокси к API Filmix (Cloudflare Worker)
proxy/server.js     — тот же прокси под Node 18+ (VPS / домашний сервер)
```

## Как это работает

Плагин использует API приложения Filmix (`filmixapp.cyou/api/v2`):

- `search?story=<название>` — поиск;
- `post/<id>` — озвучки, сезоны и прямые ссылки на mp4 во всех качествах.

Без PRO-аккаунта API отдаёт ссылки до 2160p. Токен Filmix нужен только для PRO-функций.

### Зачем нужен прокси

Если запрос пришёл с браузерным User-Agent (`Mozilla…`, `Chrome…`), Filmix отдаёт пустой список ссылок. Изменить UA из Lampa нельзя ни в браузере, ни в WebView на ТВ и Android, поэтому запросы идут через прокси с UA приложения. Заодно прокси даёт HTTPS: API Filmix работает только по HTTP. Ссылки на видео к IP не привязаны, само видео играет напрямую с CDN Filmix, без прокси.

## 1. Прокси

### Cloudflare Workers (бесплатно)

```bash
cd proxy
npx wrangler deploy
npx wrangler secret put TOKEN
```

Адрес будет вида `https://lampa-zetflix.<аккаунт>.workers.dev` (имя worker'а задано в `wrangler.toml`).

### Node

```bash
cd proxy
PORT=8787 TOKEN=секрет node server.js
```

### API прокси

Пропускаются только два метода, остальные запросы получают 404:

```
GET /filmix/search?story=<запрос>&<user_dev_*>&token=<TOKEN>
GET /filmix/post/<id>?<user_dev_*>&token=<TOKEN>
```

## 2. Установка плагина

1. Lampa → **Настройки → Расширения → Добавить плагин**:

   ```
   https://cdn.jsdelivr.net/gh/kkurbat/lampa_zetflix@master/plugin/filmix.js
   ```

   jsDelivr кэширует `@master` до 12 часов. Чтобы сразу получить свежую версию, укажите хеш коммита вместо `master`.
2. Перезапустите Lampa.
3. **Настройки → Filmix**:
   - **Адрес прокси**: адрес worker'а;
   - **Токен прокси**: значение `TOKEN`;
   - **Токен Filmix**: необязательно, для PRO.

## Использование

Карточка → **«Смотреть»** → **Filmix** (в старых версиях Lampa это отдельная кнопка рядом с «Торренты»).

- Плагин ищет тайтл по русскому, затем по оригинальному названию и сверяет год. Если однозначного совпадения нет, показывает список вариантов. Выбранный тайтл запоминается (`filmix_online_ids`).
- Стрелка вправо открывает фильтр: озвучка и сезон. В поиске фильтра можно уточнить название вручную.
- Долгое нажатие ОК открывает выбор плеера и копирование ссылки нужного качества.

## Ограничения

- Часть фильмов на Filmix «Заблокировано правообладателем»: такие варианты плагин скрывает.
- Если Filmix сменит домен API, поменяйте `FILMIX_API` в настройках worker'а (`wrangler.toml` → `[vars]`) и выполните `wrangler deploy`.
