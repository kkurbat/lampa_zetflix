# Zetflix для Lampa

Плагин-источник для [Lampa](https://github.com/yumata/lampa): фильмы и сериалы с Zetflix, выбор озвучки, сезона и качества, таймкоды, отметки «просмотрено».

```
plugin/zetflix.js   — плагин Lampa (ES5, без сборки)
proxy/worker.js     — прокси: проходит защиту Zetflix и отдаёт JSON (Cloudflare Worker)
proxy/server.js     — тот же прокси под Node 18+ (VPS / домашний сервер)
```

## Зачем нужен прокси

Lampa в браузере или на ТВ не может обращаться к Zetflix напрямую:

1. У Zetflix нет CORS-заголовков.
2. Перед плеером стоит JS-челлендж: страница отдаёт `window.token`, затем нужно отправить
   `POST` с `Authorization: Bearer <token>` и `hash = sha1(md5(token + ';' + hostname + ';' + userAgent))`.
   Сессия хранится в HttpOnly-куке `PHPSESSID`.
3. Без `Referer` с домена Zetflix сервер отвечает «Это видео удалено».

Из браузера нельзя ни выставить `Referer`, ни работать с чужой HttpOnly-кукой, поэтому эти шаги выполняет прокси.

## 1. Запуск прокси

### Cloudflare Workers (бесплатно)

```bash
cd proxy
npx wrangler deploy
```

После деплоя появится адрес вида `https://lampa-zetflix.<аккаунт>.workers.dev`.
Чтобы прокси не был открыт для всех, задайте токен:

```bash
npx wrangler secret put TOKEN
```

### Node (VPS, домашний сервер, роутер)

```bash
cd proxy
PORT=8787 TOKEN=секрет node server.js
```

Проверка:

```bash
curl "http://localhost:8787/?kp=301"
```

### API прокси

`GET /?kp=<id Кинопоиска>[&season=<номер>][&token=<TOKEN>]`

```jsonc
// фильм
{ "ok": true, "type": "movie", "voices": [{ "name": "Дубляж", "qualities": { "1080p": "https://…", "720p": "…" } }] }
// сериал (один сезон за запрос)
{ "ok": true, "type": "serial", "season": 1, "voices": [{ "name": "LostFilm", "episodes": [{ "episode": 1, "qualities": { … } }] }] }
// ошибка
{ "ok": false, "error": "not_found" }
```

Переменная `ZETFLIX_BASE` (по умолчанию `https://hdi.zetflix.online`) — входной адрес. Он сам перенаправляет на действующее зеркало, а прокси берёт имя хоста для хеша уже после перенаправления.

## 2. Установка плагина

1. В Lampa: **Настройки → Расширения → Добавить плагин** и вставьте URL:

   ```
   https://cdn.jsdelivr.net/gh/kkurbat/lampa_zetflix@master/plugin/zetflix.js
   ```

   jsDelivr кэширует `@master` до 12 часов. Чтобы сразу получить свежую версию, укажите хеш коммита вместо `master`.
2. Если нужен свой хостинг, подойдёт любой HTTP(S)-адрес файла `plugin/zetflix.js`.
3. **Настройки → Zetflix**: укажите адрес прокси и, если задавали, токен.

В карточке фильма или сериала источник **Zetflix** появится в меню кнопки «Смотреть» (в Lampa 3.x) или рядом с кнопкой «Торренты» (в старых версиях).

## Как определяется ID Кинопоиска

Zetflix ищет только по ID Кинопоиска, а карточки Lampa приходят из TMDB. Плагин перебирает варианты по порядку:

1. `kinopoisk_id` / `kp_id` в самой карточке (у карточек из CUB с источником KP).
2. Wikidata: TMDB ID (`P4947` для фильмов, `P4983` для сериалов) или IMDb ID (`P345`) → ID Кинопоиска (`P2603`). Без ключей, CORS разрешён.
3. Если указан ключ `kinopoiskapiunofficial.tech` — поиск по названию с учётом года.
4. Если ничего не нашлось — введите ID Кинопоиска вручную в поле поиска фильтра (число из адреса `kinopoisk.ru/film/<id>`).

Найденные ID кэшируются в `zetflix_kp`.

## Ограничения

- **Ссылки на видео** ведут на CDN `prosto.hdvideobox.me`, у ссылок ограниченный срок жизни (в пути зашито время, например `:2026101623`). Если CDN привязывает ссылку к IP, видео будет играть только там, откуда запрашивал прокси. В этом случае разверните `server.js` в той же сети, где стоит Lampa.
- Плагин берёт видео только из основного балансера zetflix (`/iplayer/videodb.php`). Часть тайтлов на сайте (например, «Тед Лассо») идёт из второго балансера (`gencit.info` → `ceramet.net`, закрыт DDoS-Guard, свои внутренние ID). Для таких тайтлов плагин покажет «На Zetflix ничего не найдено».
- Zetflix не отдаёт список сезонов, поэтому номера сезонов берутся из TMDB (`seasons` / `number_of_seasons`).
- В плейлисте одна и та же озвучка может встречаться дважды (mp4 и HLS) — вторая показывается как «Название (2)».
- При изменении обфускатора или схемы хеша на стороне Zetflix придётся обновить `extractToken` / `loadPage` в `proxy/worker.js`.
